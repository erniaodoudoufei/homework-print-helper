作业图片打印助手 1.0
====================

一、打开应用

双击“作业图片打印助手.exe”。不需要安装 Python，也不需要联网。
请保留 exe 旁边的 _internal 文件夹；移动程序时，请把整个文件夹一起移动。

二、最常用的操作

1. 把老师发来的 JPG 或 PNG 图片拖进窗口，或点“添加图片”。
   可以一次添加多张；复制图片后也可以按 Ctrl+V 粘贴。
2. 导入后自动生成建议效果。通常直接看右侧处理结果即可。
   左上角可以选“左右对比”；鼠标滚轮放大，拖动查看细节。
3. 纸边拍歪时，点“四角拉正”，把四个圆点拖到纸张四角，再点“应用”。
   如照片没拍全纸角，请沿可见纸边选择完整内容，软件不会补画缺失文字。
4. 想去掉周围桌面或多余纸边，点“裁切范围”，拖出要保留的矩形。
5. 底色偏灰时调高“去灰底强度”；细线变淡时把它调低。
   字太淡就提高“文字深浅”，太粗就降低。需要时切换“黑白”。
6. 点“打印 / 保存 PDF”，检查每一页，再点击“打印”或“保存为 PDF”。

三、爱普生 L3153 打印

这台电脑里的驱动名称是“EPSON L3150 Series”，这是应用实际选择的名称。
默认 A4、一张图片一页、单面、1 份、四周留白 5 毫米。
横向图片自动使用横向 A4，纵向图片使用纵向 A4；也可手动统一方向。
应用会兼顾打印机本身的不可打印区域，图片等比例缩放，不强行拉伸。

在预览左侧选择打印机、起止页、份数和打印颜色。
“全部黑白打印”会把彩色笔迹转为灰度，并保留细线层次。
窗口里“已提交打印任务”表示任务已交给 Windows，不代表已实际出纸。
提交后如需取消，请在 Windows 打印队列中取消。
打印机没有开机时，可以先保存 PDF。

打印纸张种类、打印质量等驱动专属设置，请在 Windows 的打印机首选项中调整。
实际颜色和清晰度还与原图、纸张、墨水和驱动设置有关。

四、文件保存

“保存处理图片”会保存当前列表中的全部图片为 PNG，使用每张图片自己的设置。
默认位置是原图旁边的“已处理”文件夹；粘贴图片默认保存到系统“图片”目录下。
同名结果自动编号。原始图片不会被覆盖。
PDF 保存的是预览中选定的页码范围；份数只影响打印，不会重复 PDF 页面。

调整记录保存在本次会话中。关闭应用前，请保存需要的 PNG 或 PDF。
关闭后再次导入原图，会重新自动处理。

五、快捷键和恢复

Ctrl+O：添加图片
Ctrl+V：粘贴图片
Ctrl+Z：撤销
Ctrl+Y / Ctrl+Shift+Z：重做
Ctrl+P：打印预览
Delete：图片列表有焦点时移除选中图片，不会删除原文件

左侧图片可以拖动排序，也可以点“上移”“下移”。
“恢复原图”同时取消拉正、裁切和效果调整；此操作也可撤销。
“重新自动处理”会重新计算当前图片的默认建议效果。
旋转或改变倾斜角度后，需要重新选择裁切范围；四角拉正后会清除之前的倾斜和裁切。
后台处理时可点“取消处理”。正在处理预览时，先等待完成再保存或打印。

六、目前的范围

面向文字、表格、手写资料；建议对细小虚线和浅色批注放大查看。
自动识别不可靠时会保留完整画面，请手动使用四角拉正和裁切。
不包含 OCR、笔迹擦除、扫描仪采集、PDF 导入、拼页和弯曲书页展平。
低分辨率照片能够改善底色和对比，但不能恢复原图没有记录的笔画细节。

本版本已经完成软件和导出检查；未自动向实体打印机发送测试页。
